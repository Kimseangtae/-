## 글쓰기 기본값
- 후킹 4단계: ① 상식 뒤집기·강한 주장 ② 반론 예상("이렇게 알고 계시죠?") ③ 반론 제거("근데 그게 오히려") ④ 본론 유인
- 전개: 문제 → 불편 → 손해 → 해결 가능성. 문장은 짧게, 한 문장 한 메시지. 결론부터.
- 추상어 금지, 생활 장면으로. "좋다/맛있다" 전에 이유 먼저.
- 설득은 사례 + 비교 + 손해 회피. 부정 사례는 1인칭(나), 긍정 사례는 3인칭(타인).
- 숫자로 계산해준다(가격 앵커링: "개별로 사면 약 10만 원 vs 이건 3만 원대"). **실제 가격만.**
- 신뢰: 한계 인정 → 그럼에도 쓰는 이유 → CTA. 단점을 먼저.
- 글 마지막은 지금 할 행동 **1개**.
- 완성본만 낸다. 자리표시자 금지. 정보가 부족하면 쓰지 말고 물어본다.

## 영상 대본 (6막, 30분 기준)
썸네일 문구 + 제목 후보를 **먼저** 확정한 뒤 인트로.
- [0막] 콜드 오픈 0~60초: 완성샷 또는 가장 충격적인 한 컷. 정답은 보여주지 않는다.
- [1막] 문제 제기 1~4분: 시청자 불편을 대신 말해준다.
- [2막] 재료+영양 4~10분: 재료마다 '왜' 1개, 손해 회피로.
- [3막] 조리+셰프의 킥 10~22분: 비법 2~3개로 쪼개 배치, 비법 직전 브릿지 자막.
- [4막] 시식+인간적 대화 22~28분: 맛 평가가 아닌 '변화' 서사 1개.
- [5막] 정리+CTA 28~30분: 비법 3가지 자막 요약 + 멤버십 유도.
- 본문 6요소: 주장·근거·원리·예시·반론·대안. 편집 장치: 브릿지 자막 / 티저 자막 / 90초마다 변화 / 카메라 리듬.
- 속도·말투·동작 변화 지점은 [강조] 태그. 인트로는 공감→후킹→본론, 30초 안에.
- 중간 구독 CTA 1회. 클로징: 개인 서사 1~2개 + 계절/날씨/감정 공감 + 그날 요리 연결 + 구독/좋아요.
- 썸네일 문구 14~18자, 정답 노출 금지, 숫자 활용. 컬러: 핵심=빨강, 서포팅=노랑, 비교=파랑 vs 빨강. 제목은 긴장 프레임 후보 3개 이상.

## 플랫폼 규격
- **유튜브 롱폼 설명글(이 순서)**: ① 해시태그 3개(#로빈의밥상 필수) ② 후킹 도입(핵심 키워드 3회 자연 반복) ③ 재료(이름+수량, 단위 생략) ④ 조리 단계 최대 8줄·1줄 1동작·25자 이내 ⑤ 타임라인 챕터 8~10개, 첫 줄 `00:00 | 인트로`, 챕터마다 키워드 2개 ⑥ CTA("밥상 식구님들" 필수, 멤버십 링크) ⑦ 저작권 표기
- **고정 댓글**: 정확히 3줄(구매 링크 포함해서 3줄). 공구용은 후킹 → 긴장 → 해소 단서 → CTA 압축. 3종: 공감 선행형 / 손해 회피형 / 신뢰 구축형.
- **쇼츠 설명글**: 후킹 제목 30자 이내 / 본문 약 300자 / 해시태그 3개(#로빈의밥상 필수).
- **릴스**: 해시태그 금지. SEO + 공감 후킹. 존댓말. 프로필 링크 CTA.
- **스레드**: 반말체. 유형은 생활 밀착 / 발견 공유 / 소신발언 중 하나. 강한 훅 + 상식 뒤집기 + 참여형 마무리.
- 같은 내용을 다른 플랫폼에 옮길 때는 호칭·어미를 그 플랫폼 기준으로 다시 쓴다.

## 공동구매 콘텐츠
- **정보 다큐 위장**: 카테고리 교육 90% + 자연스러운 제품 노출. 광고처럼 보이는 순간 실패.
- 소구점 3축: **난이도 해소 / 속도 향상 / 선택 대행**.
- 퍼널: 일반 영상 → 고정 댓글 → 키 콘텐츠 영상 → 구매 링크.
- **검증형 6단계(쇼츠·릴스)**: 행동 차단 후킹 → 상식 뒤집기 → 손해의 3중 구체화 → 시각 증거 → 가족 보호 → 참여형 CTA.
- 마감 장치: 한정 수량 + 조기 종료 가능성 + 오픈 일시 + 알림 유도. **실제 조건만, 과장 금지.**
- 신뢰: 장점만 나열 금지. 단점 1개 이상을 먼저 짚고 CTA.
