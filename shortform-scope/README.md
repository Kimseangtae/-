# 밥상스코프 — 숏폼 분석 크롬 확장

인스타 릴스 · 쓰레드 영상 · 유튜브 쇼츠를 보다가 버튼 하나(또는 `Alt+Shift+R`)로
그 영상을 **초 단위로 측정**하고, **훅·감정·서사 점수**를 매기고, **로빈의밥상 소재 콘티**로 바꿔 주는 개인용 도구입니다.
reelscope.kr의 핵심 기능을 개인용으로 다시 만든 것입니다. 회원가입, 크레딧, 결제 기능은 없습니다.

## 할 수 있는 것

| 기능 | 내용 | 어디서 계산하나 |
|---|---|---|
| 컷·샷 측정 | 컷 위치(1/30초 단위), 샷 길이·프레임 수, 평균 샷 길이, 분당 컷 수 | 브라우저에서 직접 측정 |
| 카메라·색 | 샷별 움직임(고정/약한/큰), 평균 색, 밝기 | 브라우저에서 직접 측정 |
| 소리·박자 | 0.5초 단위 소리 크기 곡선, BPM, 박자에 맞은 컷 비율, 4박 세로선 | 브라우저에서 직접 측정 |
| 훅·감정·서사 점수 | 100점 만점 3종 + 종합, 붙잡는 순간·풀리는 순간(초), 훅 유형 이름 | Claude |
| 감정 곡선 | 시청자 몰입도 곡선을 실제 소리 크기와 겹쳐 표시 | Claude + 측정값 |
| 댓글 반응 | 반복되는 반응을 유형별로 묶어 비율 표시. 작성자 이름은 수집 안 함, @멘션 가림 | Claude |
| 자막 대본 | 화면 글자(자막) 시간순 정리 | Claude |
| 콘티 3종 | ① 로빈의밥상 소재 콘티(썸네일·제목·콘티표·자막·쇼츠 설명글) ② 샷 리듬 역산 콘티 ③ 영상 생성 도구용 프롬프트 | Claude |
| 기록·내보내기 | 분석 기록 저장(이 브라우저에만), 마크다운 저장·복사, PDF 인쇄 | — |

콘티에는 채널 규칙이 자동으로 들어갑니다(`prompts.js`의 `CHANNEL_RULES`). 예를 들어 매실액을 쓰지 않고, "채칼"로 표기하고, 쇼츠 설명글은 "본 영상"으로 유도하고, `#로빈의밥상`을 넣습니다.

## 설치 (PC 크롬, 5분)

1. 이 저장소를 내려받습니다. GitHub에서 **Code → Download ZIP** 을 누르고 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` 를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `shortform-scope` 폴더를 선택합니다.
5. 퍼즐 조각 아이콘을 누르고 **밥상스코프**를 고정(핀)합니다.

## Claude API 키 받기 (처음 한 번)

분석 두뇌로 Claude를 씁니다. 키는 이 컴퓨터의 크롬 확장 저장소에만 저장되고, Anthropic 외의 곳으로는 보내지 않습니다.

1. https://console.anthropic.com 에 들어가 구글 계정으로 가입합니다.
2. 왼쪽 메뉴 **Billing**에서 카드를 등록하고 5달러(약 7천 원)를 충전합니다. 다 쓰면 다시 충전하는 선불 방식입니다.
3. **API Keys → Create Key** 를 누릅니다. 이름은 `밥상스코프`처럼 아무거나 넣습니다.
4. `sk-ant-`로 시작하는 키가 나오면 복사합니다. 이 화면을 닫으면 다시 볼 수 없으니 바로 붙여넣으세요.
5. 밥상스코프 아이콘을 누르고 **⚙ 설정** 탭에서 키를 붙여넣은 다음 **저장**을 누릅니다.

**비용 감(추정)**: Opus 5.5 · 분석 깊이 '보통' 기준으로 분석 1편에 약 100~250원, 콘티 1개에 약 100~200원입니다. 각 리포트 아래에 추정 금액이 표시됩니다. 더 아끼려면 설정에서 모델을 Sonnet 5.5로 바꾸세요.

## 쓰는 법

1. 인스타·쓰레드는 로그인한 상태에서, 분석하고 싶은 릴스를 화면에 띄웁니다. 유튜브 쇼츠도 같습니다.
2. 밥상스코프 아이콘을 누르거나 `Alt+Shift+R` 을 누르고, **▶ 지금 보는 영상 분석**을 누릅니다.
3. 영상이 처음부터 한 번 재생되며 측정합니다. 이때 소리가 납니다. 이어서 Claude가 30초~1분 동안 분석합니다.
4. 리포트 아래 **콘티 만들기**에 새 소재(예: `알룰로스로 만드는 무 깍두기`)를 적고 콘티 종류를 고릅니다.

**댓글 반응을 넣고 싶을 때**: 분석 전에 영상의 댓글 창을 열고 조금 스크롤해 두세요. 자동 수집이 안 되면 **측정 옵션 → 댓글 직접 붙여넣기** 칸에 붙여넣으면 됩니다.

## 한계 (먼저 알고 쓰세요)

- **말(음성) 내용은 못 읽습니다.** Claude에게는 대표 장면 이미지와 측정값만 보냅니다. 그래서 대본은 화면 자막 기준입니다. 자막 없이 말로만 하는 영상은 대본이 비어 나옵니다.
- **박자(BPM)는 음악이 뚜렷할 때만 정확합니다.** 말소리 위주의 영상은 '불확실'로 표시됩니다.
- **인스타·쓰레드 댓글 자동 수집은 불안정합니다.** 화면 구조가 자주 바뀌기 때문입니다. 안 되면 붙여넣기를 쓰세요.
- 측정하는 동안 영상을 끝까지 재생해야 해서, 60초 영상이면 측정에 60초가 걸립니다. 측정 옵션에서 2배속을 고르면 절반으로 줄지만, 박자 정확도는 조금 떨어집니다.
- 3분이 넘는 영상은 앞 3분만 측정합니다.
- 다른 사람의 영상을 그대로 다시 만드는 용도가 아닙니다. 구조를 배우고 내 소재로 다시 만드는 데 쓰세요.

## 파일 구성

```
shortform-scope/
├── manifest.json     크롬 확장 설정 (MV3)
├── background.js     단축키 → 사이드 패널 열기
├── content.js        측정 엔진: 컷·샷·움직임·색·소리·BPM·대표 장면·캡션·댓글
├── claude.js         Claude API 호출 (분석은 JSON 형식 고정 응답, 콘티는 마크다운)
├── prompts.js        분석/콘티 지시문, 채널 고정 규칙, 응답 형식
├── sidepanel.html    화면
├── sidepanel.css
└── sidepanel.js      화면 동작, 차트, 기록, 내보내기
```
