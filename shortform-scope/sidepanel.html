분석 두뇌로 Claude를 씁니다. 키는 이 컴퓨터의 크롬 확장 저장소에만 저장돼요.

  1. console.anthropic.com 에 구글 계정으로 가입
  2. 왼쪽 메뉴 Billing에서 카드 등록 후 5달러(약 7천 원) 충전
  3. API Keys → Create Key → 나온 키를 복사해서 위 칸에 붙여넣기
