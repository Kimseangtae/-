예시 데이터로 실제 실행한 것
- 입력·수정: 화면에서 새 기록(자동 ID) 저장 → 다시 불러와 수정 → 저장, 같은 ID 추가는 원인·해결 방법과 함께 거부.

- 메뉴 평가: 한식·일식·지중해식 6개 후보. 자동(규칙) 점수와 셰프 점수 분리, 근거 없는 기준은 "보류", 최종판단은 실행 후에도 입력값 그대로(자동 확정 없음).

- FAQ: 셰프확인+근거 있는 답(Q002)만 답변, 나머지는 "확인 필요". 구매 망설임 댓글(C008)도 질문으로 포함, 판매 결과 행은 제외.
- 수정·재저장·이전 버전: 셰프가 고친 대본은 조리 기록이 바뀐 뒤 다시 만들어도 유지, 새 생성본은 따로 보관, 교체 시 이전 수정본 보관, 변경기록.csv에 기록. 고치지 않은 초안은 새 기록으로 갱신되고 이전 판은 이전본에 남음.
- 성과 회고: 유튜브 24시간끼리만 비교, 인스타 단독은 판단 안 함, 경과시간 없는 V004는 비교 제외. 선예약 12건은 주문으로 세지 않음, 전환율은 주문 8 ÷ 분모 200일 때만 4.0%.
