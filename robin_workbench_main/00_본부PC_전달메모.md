# 요리·공구 작업실 2.0 소스 (main PC, 2026-09-30 기준)

클라우드 세션 요청("1.0 압축본")에 대한 답입니다. 이 PC의 구글 드라이브·크롬 자동 업로드가 zip 같은 바이너리 파일을 받지 못해, zip 대신 **소스 파일을 텍스트 그대로** 올렸습니다. 1.0이 아니라 이미 개선된 **2.0**입니다. main에서 로빈님 직접 요청으로 개선을 마쳤으니 중복 개선하지 말고, 이 소스를 기준으로 이어 가세요.

## 파일
- `app.py` 화면(tkinter), `core.py` 핵심 기능, `schema.py` 입력 양식·분류 규칙, `seed.py` 예시 자료·양식 생성
- `test_workbench.py` 자동 검사 38개 (`python -m unittest -v test_workbench.py`)
- `README.md` 사용법, `검증결과.md` 검증 범위, `자료검토와적용.md` 자료 검토 기록

## 실행
같은 폴더에 두고 `python app.py` (Python 3.13, 추가 설치 없음). 처음 실행하면 `data/example`, `templates`, `입력안내.md`가 **자동으로 만들어집니다**(그래서 올리지 않았습니다). 창 없이 확인하려면 `python app.py --run example`. 결과는 `다운로드\로빈_작업실_결과`에 저장됩니다.

## 올리지 않은 것
- `data/actual`, `backups`, 실행 결과(실제 입력 자료는 비어 있었고, 원문이 있을 수 있어 제외)
- 카카오톡 대화 파일
- `start.cmd`, `example.cmd` (각각 `python app.py`, `python app.py --run example` 을 실행하는 한글 배치 파일)

## 줄바꿈 참고
main의 원본 일부는 윈도우 줄바꿈(CRLF)이고 여기 올린 파일은 LF입니다. 파이썬 코드로는 동일합니다. `test_workbench.py`의 BOM 문자는 `﻿` 이스케이프로 적었습니다.

## 지켜야 할 규칙(요약)
셰프확인된 조리 기록만 초안 원본, 셰프가 고친 초안은 재생성해도 덮어쓰지 않음, 분류는 '규칙 기반'(AI 아님), 선예약은 주문·매출 아님, 빈 값은 0이 아니라 미수집, 게시·발송 기능 없음. 자세한 내용은 README.md.
