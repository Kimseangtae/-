# 로빈의밥상 — 요리·공구 작업실 2.0

시청자 불편 → 메뉴 후보 → 조리 테스트 → 콘텐츠 초안 → 공구 FAQ → 성과 회고 → 다음 메뉴 기획.
이 PC에서만 돌아가는 앱입니다. 설치·가입·키 입력이 없고 요금이 들지 않습니다. 맛·안전·상품 판단과 최종 메뉴·게시물 결정은 셰프가 합니다.

## 처음 실행

1. `start.cmd`를 더블클릭합니다.
2. 오른쪽 위가 **예시 연습**인 상태에서 **④ 콘텐츠 초안 → 초안 만들기**를 눌러 결과를 구경합니다.
3. 실제로 시작할 때 오른쪽 위를 **실제 운영**으로 바꿉니다. 화면 위 띠 색이 노랑(예시) → 초록(실제)으로 바뀝니다.
4. 위쪽 여섯 단계 버튼이 지금 단계(노랑)와 부족한 자료(빨간 글씨)를 알려 줍니다. 버튼을 누르면 그 화면으로 갑니다.

`example.cmd`는 창 없이 예시 전체 흐름만 실행하고 결과 폴더를 엽니다.

## 테마 밥상 추천 (2.1)

③ 메뉴 선정 → **테마 밥상 추천**. 생년월일(선택)과 성격유형 네 글자(선택)를 넣으면 선택일 일진·띠·연간 오행·별자리·성격유형으로 메뉴 후보를 좁혀 `결과\테마밥상` 폴더에 저장합니다.
- 규칙 기반이며 재미·기획용입니다. 운세 문장은 만들지 않고, 역법으로 계산되는 값만 씁니다. 건강·맛·안전 판단이 아닙니다.
- 메뉴후보에 새 칸 **색 · 맛 · 스타일태그**를 채워야 추천에 반영됩니다(선택 입력). 비워 두면 0점이 아니라 "평가 보류"로 표시됩니다.
- 최종 메뉴는 여전히 [최종판단]에 셰프가 직접 넣습니다. 이 기능은 후보를 좁혀 줄 뿐 자동 확정하지 않습니다.
- 2.0 실제 입력 파일은 처음 열 때 새 칸이 빈 값으로 추가되고, 원본은 `backups\actual\*_양식갱신전.csv`에 남습니다.

## 지키는 규칙

- **셰프확인된 조리 기록만** 콘텐츠 초안의 원본이 됩니다. 기록에 없는 재료량·시간·불 세기·효능·성능은 쓰지 않고 "확인 필요"로 남깁니다.
- **셰프가 고친 초안은 다시 만들어도 덮어쓰지 않습니다.** 새 자동 생성본은 `_기록\생성본`에 보관되고 목록에 ●로 표시됩니다. [새 생성본 보기]로 비교하고, 원하면 [새 생성본으로 교체](이전 수정본 보관).
- 키 콘텐츠(상품 집중 검증)와 풀링 콘텐츠(메뉴 중심)를 구분합니다. 상품 기능은 공식 출처와 "확인" 표시가 있을 때만 씁니다. 필요 없는 분·구매 전 비교 조건을 함께 적습니다.
- 성과는 **같은 플랫폼·같은 게시 후 경과시간**끼리만 비교합니다. 빈 값은 0이 아니라 "미수집"입니다.
- **선예약은 주문·매출로 계산하지 않습니다.** 전환율은 확정 주문과 분모가 모두 있을 때만 계산합니다.
- 분류는 **규칙 기반**(표현 목록)입니다. AI 분석이라고 부르지 않습니다. 영상 아이디어는 "추정"으로 표시합니다.
- 최종 메뉴는 메뉴후보의 [최종판단]에 셰프가 직접 "선택"을 넣습니다. 앱은 자동 확정하지 않습니다.
- 예시 행(원문이 `[예시]`로 시작하거나 구분=예시)은 실제 모드에 들어가지 않습니다.
- 결과물의 전화·이메일·닉네임 일부를 가리지만 완벽하지 않습니다. 이름·주소·연락처는 입력 단계부터 빼 주세요.

## 이 버전이 하지 않는 것

외부 AI 호출, 유튜브·인스타 게시, 댓글 답글, DM, 알림톡 발송, 상품 정보 변경, 로그인·API 연결. 기존 공구 자동화나 다른 PC 예약 작업을 바꾸지 않습니다.
외부 AI를 나중에 붙인다면 기본은 꺼 두고, 보낼 자료와 예상 비용을 먼저 보여 준 뒤 셰프가 켜는 방식으로 추가합니다.

## 백업과 복원

- [백업·도움말] → [지금 백업]: 현재 모드의 입력 CSV와 초안을 zip 하나로 저장.
- [백업에서 복원]: zip을 검사한 뒤, 지금 자료를 먼저 자동 백업하고 입력 자료를 되돌립니다. 모드가 다른 백업이나 손상된 zip은 거부합니다.
- 앱 폴더 전체 복사도 백업이 됩니다. `data\actual`, `backups`에는 원문이 있으니 공유하지 마세요.

## 명령으로 실행 (선택)

- `python app.py` — 화면
- `python app.py --run example` / `--run actual` — 창 없이 전체 흐름
- `python app.py --out D:\다른폴더` — 결과 위치 바꾸기
- `python -m unittest -v test_workbench.py test_theme_menu.py` — 자동 검사 58개

## 1.0에서 2.0으로

1.0 자료는 그대로 읽습니다. 실제 입력 CSV는 새 칸(플랫폼·검토상태·확인시각·모델 등)을 빈 값으로 추가하고 원본을 `backups\actual\*_양식갱신전.csv`에 남깁니다. 1.0 예시·양식은 `backups\이전예시_*`, `backups\이전양식_*`로 옮겼습니다. 1.0이 만든 `outputs` 폴더의 결과도 그대로 둡니다.
