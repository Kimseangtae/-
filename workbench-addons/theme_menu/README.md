# 테마 밥상 추천 — 요리·공구 작업실 추가 부품

바디프랜드 안마의자의 "사주운세·성격유형·별자리 테마 마사지"(2026년 다빈치 AI·733 등) 구조를 요리에 옮긴 부품입니다.
기질 정보 → 테마 풀이 → 성향에 맞는 추천 → "나와 연결된 재미". 마사지 대신 **메뉴 후보**를 추천합니다.

## 무엇을 하나
| 테마 | 넣는 값 | 계산하는 것 | 메뉴와 맞추는 기준 |
|---|---|---|---|
| 선택일 밥상 | 날짜(기본 오늘) | 일진(60갑자) → 일간 오행 | 전통 오행 색·맛 + 상생 오행 색 |
| 띠·오행 밥상 | 생년월일 | 띠, 연간 오행 (입춘 기준, 2월 3~5일생은 "확인 필요") | 위와 같음 |
| 별자리 밥상 | 생년월일 | 별자리와 원소(불·흙·공기·물) | 스타일 태그 |
| 성격유형 밥상 | MBTI 네 글자 | 글자별 요리 성향 | 스타일 태그 |

마지막에 시리즈·제목·썸네일·댓글 참여 아이디어 초안과 셰프 확인 칸을 붙입니다.

## 지키는 원칙
- 규칙 기반입니다. 외부 AI·인터넷을 쓰지 않습니다. 결과물에도 "규칙 기반"이라고 적습니다.
- 운세 문장을 지어내지 않습니다. 역법으로 계산되는 값만 씁니다. 연간 오행만 쓴 간이 풀이이며 정식 사주풀이가 아닙니다.
- 오행 색·맛은 전통 배속(재미·기획용)입니다. 건강 효능 주장이 아닙니다.
- 태그가 빈 메뉴는 0점이 아니라 "평가 보류"입니다.
- 한 파일에 예시와 실제를 섞으면 멈춥니다. 결과 파일 이름에 예시/실제가 붙습니다.
- 최종 메뉴는 셰프가 고릅니다.

## 실행 (윈도우)
`테마밥상_예시실행.cmd`를 더블클릭하면 예시 결과가 `다운로드\로빈_테마밥상추천`에 저장되고 폴더가 열립니다.

직접 실행:
```
python theme_menu.py --menus 메뉴후보.csv --birth 1966-09-10 --mbti ISFJ --day 2026-10-05
```

## 메뉴 후보 CSV
필수 열: `메뉴ID, 메뉴명, 데이터구분(예시/실제)`
선택 열: `요리권역, 색(청·적·황·백·흑), 맛(신맛·쓴맛·단맛·매운맛·짠맛), 스타일태그, 셰프확인`
스타일태그 예: 국물, 찜, 오래끓이기, 센불, 빠른조리, 한그릇, 1인분, 여럿나눔, 단계적, 계량정확, 원리설명, 추억음식, 퓨전, 냉장고파먹기, 뿌리채소, 가벼운, 샐러드
엑셀 CSV(cp949)와 CSV UTF-8 모두 읽습니다.

## 기존 작업실 앱과 연결 (다음 단계)
기존 앱 소스(`robin_workbench`)는 본부 PC 로컬에만 있어 이 부품을 아직 화면에 붙이지 못했습니다.
소스를 받으면 ⑥ 메뉴 후보 화면에 "테마 추천" 버튼과 태그 칸을 추가하고, 결과를 콘텐츠 초안 단계로 넘깁니다.

## 검증
```
python -m unittest -v test_theme_menu
```
16개: 일진 기준일 2개(2000-01-01 무오, 1900-01-01 갑술), 입춘 경계, 별자리 경계 7개, 성격유형 오입력, 파일 없음·열 누락·중복 ID·예시/실제 혼합·잘못된 구분값·엑셀 인코딩, 태그 없음 보류, 추천 근거 추적, 금지어 미포함, 실행·오류 종료 코드.
