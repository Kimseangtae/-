| 첨부 이미지 4장 | 아래 2절 |

본부 받는함에 1.0 압축본을 Drive에 올려 달라는 요청을 남겼습니다(허브 `hub/inbox/main/…요리공구작업실-압축본…`).
압축본이 오면 1.0과 2.0을 비교해 빠진 기능을 옮기고, 1.0 자료를 2.0으로 가져오는 과정을 시험합니다.

## 3. 작업실에 옮긴 방식 — 테마 밥상 추천 (3 메뉴 후보 탭)
| 이미지의 구조 | 작업실 적용 |
|---|---|
| 사주운세(생년월일시) | 선택일의 일진과 일간 오행, 태어난 해의 띠와 연간 오행. 역법으로 계산되는 값만 사용 |
| 오늘·내일·선택일 운세 | 날짜를 넣으면 그날 일진 기준 추천(운세 문장은 만들지 않음) |
| 성격유형 | 네 글자 성격유형 → 요리 성향 태그(1인분·계량정확·추억음식 등) |
| 별자리 | 별자리 원소 → 요리 성향 태그(국물·찜·센불 등) |
| 성향에 맞는 마사지 추천 | 메뉴 후보의 색·맛·스타일 태그와 맞춘 추천, 맞은 이유를 한 줄씩 표시 |
| 흥미로운 연결고리 | "12띠 밥상", "별자리 밥상" 시리즈·제목·썸네일·댓글 참여 초안 |

지킨 선:
- 결과마다 "재미·기획용, 규칙 기반"을 표시합니다. 오행 색·맛은 전통 배속이며 건강 효능 주장이 아닙니다.
- 연간 오행만 쓴 간이 풀이이며 정식 사주풀이가 아닙니다. 2월 3~5일생은 입춘 경계라 "확인 필요"로 표시합니다.
- 일진 기준일(2000-01-01 무오일)은 만세력 자료와 대조했습니다.
- 태그가 빈 메뉴는 추천에서 빼고 "평가 보류"로 표시합니다. 최종 메뉴는 셰프가 고릅니다.

## 4. 요청 사항 반영표
| 요청 | 반영 위치 |
|---|---|
| 자료 7종 입력·수정·CSV 가져오기/내보내기, 예시와 작성 안내 | 1 자료 입력, 3, 4, 6 탭의 공통 입력 화면, "빈 양식 받기" |
| 원문·셰프 확인·자동 추정 구분 저장 | 칸마다 성격 표시(색), 자동 결과는 별도 저장(`_auto`), 가져온 추가 열은 `_extra` |
| 예시/실제 분리, 빈 값은 0이 아님 | 모드별 폴더, EX- 접두어, 실제 모드에 예시 줄 거절, 빈 값은 "미확보" |
| 불편 7분류·주제 묶음·대표 댓글·원문 추적·영상 아이디어·추정 표시 | 2 불편 분석 |
| 메뉴 6기준 1~5점, 자동/셰프 분리, 보류, 셰프가 최종 선택 | 3 메뉴 후보 |
| 조리 기록 기반 초안 12항목, 키/풀링 구분, 수치 임의 추가 금지, 확인 필요 표시, 근거 ID 연결 | 5 콘텐츠 초안 |
| 수정·재저장·재생성 시 수정본 유지·버전·변경 기록, "완성 영상 아님" | 5 콘텐츠 초안 |
| 같은 플랫폼·같은 경과시간 비교, 선예약≠주문, 전환율 조건부 계산, 회고 검색 | 6 성과 회고, 3 메뉴 후보의 회고 검색 |
| 단계·부족 자료 표시, 오류 원인과 해결 방법, 결과 폴더 열기, 백업·복원, 다운로드 저장 | 시작 탭, 모든 오류 창 |
| 게시·발송·외부 AI 없음, 비밀값 저장 없음 | 해당 기능 없음 |
