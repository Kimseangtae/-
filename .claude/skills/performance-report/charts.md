# 로빈의밥상 차트 고르기 (요청 문장 포함)

성과를 그림으로 볼 때 쓰는 차트 이름과, 클로드·코덱스에게 그대로 말하면 되는 요청 문장.
스레드 @hoodi_ux 의 "차트 용어 30가지" 글에서 **로빈님 일에 쓸 9가지만** 골라 로빈님 상황으로 다시 썼다.

| 알고 싶은 것 | 차트 | 이렇게 말하기 |
|---|---|---|
| 공구가 언제 겹치나 | **간트 차트** | "다음 두 달 공구 판매 기간을 간트 차트로 보여줘. 겹치는 기간은 따로 알려줘." |
| 공구끼리 주문 비교 | **테이블 바 차트** | "공구별 주문 수를 표로 보여주고, 각 줄에 주문 수만큼 막대를 넣어줘." |
| 문의가 어디 몰리나 | **파레토 정렬** (막대 + 누적 비율 글자) | "고객 문의를 유형별로 많은 순서대로 막대로 보여주고, 누적 비율은 숫자로 붙여줘." |
| 업로드가 끊긴 날 | **캘린더 히트맵** | "최근 12주 동안 날짜별 업로드 수를 캘린더 히트맵으로 보여줘. 많을수록 진하게." |
| 최근 흐름만 짧게 | **스파크라인** | "구독자 수 옆에 최근 7일 변화를 스파크라인으로 넣어줘." |
| 목표 대비 얼마나 왔나 | **불릿 차트** | "이번 공구 주문 수를 불릿 차트로 보여줘. 실적은 막대, 목표는 기준선으로." |
| 어디서 빠져나가나 | **퍼널 차트** | "조회 → 구매 링크 클릭 → 주문 단계별 사람 수와 전환율을 퍼널 차트로 보여줘." |
| 바꾸기 전후 비교 | **덤벨 차트** | "썸네일 바꾸기 전후 클릭률을 영상별 덤벨 차트로 비교해줘. 전은 연하게, 후는 진하게." |
| 언제 올려야 반응이 좋나 | **히트맵** (요일 × 시간) | "요일과 시간대별 평균 조회수를 히트맵으로 보여줘." |

## 지킬 것
- **축은 하나.** 막대(건수)와 선(비율)을 왼쪽·오른쪽 두 축에 겹치는 차트(원래 파레토 차트 모양)는 읽기 어렵다. 비율은 숫자로 붙이거나 차트를 둘로 나눈다.
- 플랫폼끼리 숫자를 한 차트에 섞지 않는다(유튜브 조회 vs 인스타 도달은 단위가 다르다). 플랫폼마다 따로.
- 정산금·마진 같은 내부 숫자는 공개 저장소 파일에 쓰지 않는다. 운영센터(비공개)에서만 본다.
- 표본이 5개 미만이면 "가설"이라고 적는다.
- 운영센터에는 간트(공구별 대시보드), 테이블 바·파레토 정렬(성과 한눈에)이 이미 들어가 있다.
