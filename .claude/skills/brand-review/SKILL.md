# /brand-review — 과장·금지어·톤 검수

## 순서
1. 대상: 인자로 받은 파일·소재 ID·붙여넣은 글. 소재 ID 면 `content-hub/out/<ID>/` 의 모든 파일.
2. 기계 검사: `python gongu-lab/lint_content.py <파일들>` (금지어·자리표시자·플랫폼 규격·과장 의심).
3. **독립 검수(검증 루프)**: 공구 오픈 글·키 콘텐츠·썸네일처럼 큰 건은 Agent 를 새로 띄워 같은 파일을 맡긴다.
   그 에이전트에게는 `gongu-lab/guidelines.md` 경로와 파일 경로만 주고, 내 판단은 주지 않는다(내 의견에 끌려가지 않게).
4. 사람 눈 검사 항목 (기계가 못 잡는 것)
   - 과장: 역대급·1등·최고·완벽·무조건·기적·"이것만 있으면" → 사실 문장으로
   - 근거 없는 효능·건강 주장, 확인 안 된 가격 비교·수량·마감
   - 단점이 장점보다 뒤에 있거나 없음 → 단점 1개를 앞으로
   - '20년 셰프' 0회 또는 2회 이상
   - 썸네일·제목이 정답(비법 핵심)을 말해 버림
   - 플랫폼 호칭·어미 섞임, 문장이 길거나 추상적인 표현
   - 광고처럼 보이는 문장(정보 다큐 90% 원칙 위반)
5. 결과 표: | 위치 | 원문 | 문제 | 고친 문장 |. 로빈님이 승인하면 파일에 반영하고 lint 다시.

## 하지 않는 것
- 사실을 새로 지어 넣지 않는다. 고친 문장은 원문에 있던 사실만 쓴다.
